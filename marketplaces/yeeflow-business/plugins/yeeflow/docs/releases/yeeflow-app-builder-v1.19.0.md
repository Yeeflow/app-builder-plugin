# Yeeflow App Builder 1.19.0

Adds three specialist skills and enhances six existing skills, with 31 skills in the Codex and Claude distributions. See [the RC scope](yeeflow-app-builder-v1.19.0-rc1.md) and [installation verification](yeeflow-app-builder-v1.19.0-install-smoke.md).

## Included capabilities

- Workflow Stage UI: real task progress, phase gates, task-page Toggle defaults, editable demonstration separation and responsive verification.
- Single-Attachment OCR Orchestrator: applicability and upload-completion guards, scoped content-MD5 plus document-type cache, manual retry and stale-response protection.
- Document Archive Lifecycle: explicit identity/version policy, latest approved reuse, native attachment mapping and approval writeback proof.
- Focused enhancements to Approval Form, Expression, Data List, Dashboard, Custom Code and Runtime Test; existing Feature Configuration Guide retained.

The RC passed installed Codex host discovery and resource reads. Its 32 local planning tests passed from the installed cache with a foreign working directory. This final version changes release metadata and documentation; it does not claim live third-party OCR integration, a new business application acceptance test, Claude installation acceptance, or desktop visual/icon verification.

The release is eligible for stable promotion only after final-version installation and discovery are rechecked. A GitHub merge alone is not installed-host acceptance.
